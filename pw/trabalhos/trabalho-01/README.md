Descrição do projeto

O projeto consiste no desenvolvimento de um site responsivo para uma padaria, com o objetivo de apresentar seus produtos e permitir que os usuários realizem pedidos por meio de um formulário. O site será desenvolvido utilizando HTML5, CSS3 e JavaScript, com foco em responsividade, acessibilidade, organização das informações e facilidade de navegação em diferentes dispositivos.

Pré-requisitos

Para executar o projeto, é necessário ter instalado:

Visual Studio Code
Um navegador atualizado, como Google Chrome, Microsoft Edge ou Firefox
Git
Comandos de instalação

Para clonar o repositório, utilize:

git clone [https://github.com/kleberJDSilva/ra-202151119774.git]

Depois, acesse a pasta do projeto:

cd [trabalho-01]

O projeto não possui dependências externas que necessitem de instalação.

Comandos de execução

O projeto pode ser executado diretamente pelo arquivo index.html.

No Visual Studio Code, também é possível utilizar a extensão Live Server e selecionar a opção Open with Live Server no arquivo index.html.
